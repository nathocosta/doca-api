# Política de Segurança - Doca-API Backend

A privacidade dos dados e o processamento seguro de arquivos PDF em memória são os pilares fundamentais do **Doca-API**. Este documento descreve as políticas de suporte a segurança e como reportar vulnerabilidades.

---

## Versões Suportadas

O suporte de segurança é fornecido ativamente para as seguintes versões:

| Versão | Suportado |
| :--- | :--- |
| >= 0.1.0 | ✅ Sim |
| < 0.1.0 | ❌ Não |

---

## Como Relatar uma Vulnerabilidade

Por favor, **não abra uma issue pública** no GitHub para reportar problemas de segurança da API. Em vez disso, relate vulnerabilidades de forma responsável enviando uma mensagem privada ou e-mail para o mantenedor principal do projeto.

Ao relatar, forneça o máximo de informações possível:
1. Uma descrição detalhada do problema de segurança da API.
2. Passos ou uma prova de conceito (PoC) para replicar a vulnerabilidade.
3. Se o bug expõe informações temporárias na RAM ou permite bypass no controle de concorrência ou rate limiter.

Agradecemos suas contribuições para manter o processamento do Doca seguro para todos!
